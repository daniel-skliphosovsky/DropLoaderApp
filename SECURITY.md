# Security Advisory

MediaHub follows responsible disclosure practices for security vulnerabilities.

## Supported Versions

- Current stable version: v4.2.1
- Previous versions: v4.0.9, v4.0.8, v4.0.7, v4.0.6, v4.0.5, v4.0.4, v4.0.3, v4.0.2, v4.0.1, v4.0.0

## Reporting Security Issues

If you discover a security vulnerability in MediaHub, please report it responsibly:

1. **Do not disclose** the vulnerability publicly
2. **Report to the maintainers** via GitHub security advisory or private contact
3. **Provide details** about the vulnerability, impact, and reproduction steps
4. **Allow time** for the issue to be addressed before public disclosure

## Security Updates

Security updates will be released as needed. Subscribe to GitHub releases to receive notifications about security patches.

## Security Contact

For security issues, please contact the project maintainers directly through GitHub or the repository's issue tracker.

## Acknowledgments

We appreciate responsible security researchers who help make MediaHub more secure.
